# Trademark search — what I could check, and what I could not

**Date:** 2026-08-24 · **Researched by:** Claude · **Status:** partial. **Not clearance.**

`10-TRADEMARK-SEARCH.md` splits the work into a market check and a register check. I completed
the market half. **I could not complete the register half, which is the half that binds** —
and since Phase 8 is gated on clearance, this does not unblock it.

---

## 1. What I checked, and what came back

### Market / unregistered use — clean

Web and store searches for `DiAkoOi`, `Di Ako Oi`, and the phonetic variants found **no app,
game, or product** using the name on either store. That matches the preliminary signal already
recorded in §Status of the protocol doc.

Worth knowing about the neighbourhood, though: the "imposter party game" category on both
stores is **crowded**. Live titles include *Imposter Game — Party Edition*, *Imposter Who? —
Word Game*, *Impostor*, and several *Mafia* variants. None uses a Filipino name and none
collides with ours, but a category this busy raises the chance that a *descriptive* element of
a future logo or tagline runs into someone else's mark.

### Register — **not checked**

IPOPHL's search tool at `onlineservices.ipophil.gov.ph` returns **HTTP 403** to automated
requests. Its wordmark, phonetic and image searches need an interactive browser session, and I
could not reach them.

General web search is not a substitute. A register search returns *pending applications* and
*confusingly similar* marks; a web search returns things that are already visible in the
market. The whole reason §1 of the protocol calls IPOPHL "the one that binds" is that a mark
can be entirely absent from Google and still refuse your application.

## 3. What a human needs to do — about 30 minutes

Open <https://www.ipophil.gov.ph/trademark/trademark-online-tools/> in a browser and run, for
**each** of classes **9**, **41** and **28**:

**Wordmark search**

```
DiAkoOi        Di Ako Oi       DiAko Oi
Di AkoOi       DIAKOOI         Di Ako 'Oi
```

**Phonetic search** — the protocol is explicit that this is where the real risk is, because
Philippine marks get contested on sound-alikes across Tagalog, Cebuano and Spanish-derived
spellings:

```
Diako    Dyako    Di Ako    Diyako
Dakoi    Dako     Diakoy    Akoi
```

Then the same terms on ASEAN TMview and the WIPO Global Brand Database, both linked from that
page.

**Reading the result:** a conflict in class 9 is a blocker. A conflict in 41 or 28 is a
conversation with an IP lawyer, not an automatic stop.

---

## 4. The honest summary

The market check is genuinely clean and that is a real, if partial, positive signal — nobody is
selling a game under this name.

But **store search is not a trademark register**, which the protocol says in its own opening
paragraph, and the risk that matters is a confusingly similar mark in the right class that
store search structurally cannot see. Treating what I did as clearance would be exactly the
mistake §1 warns against.

**Phase 8 stays blocked.**
