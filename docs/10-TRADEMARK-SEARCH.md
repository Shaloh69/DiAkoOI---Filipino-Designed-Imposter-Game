# Trademark Search — "DiAkoOi"

**Status:** not yet cleared. Blocks Phase 8 (public site launch).
**Owner:** Hubs. **Time needed:** ~40 minutes.

A preliminary web check found no app, game, or product using "DiAkoOi" or "Di Ako Oi" on
either major store. That's a good early signal and **it is not clearance** — store search
is not a trademark register, and the risk that matters is a *confusingly similar* mark in
the right class, which store search cannot see.

---

## 1. Where to search

| Tool | URL | Use for |
|---|---|---|
| **IPOPHL search** (primary) | <https://www.ipophil.gov.ph/trademark/trademark-online-tools/> | The Philippine register. This is the one that binds you |
| ASEAN TMview | linked from the same page | Regional conflicts if you ever expand |
| WIPO Global Brand Database | linked from the same page | International marks with PH effect via Madrid |
| Google Play / App Store | store search | Unregistered use in the actual market |

IPOPHL offers **wordmark**, **phonetic**, and image search. Run wordmark *and* phonetic —
phonetic is the one that catches the real risks, since Philippine marks get contested on
sound-alikes across Tagalog, Cebuano, and Spanish-derived spellings.

---

## 2. Classes to search

Trademark protection is per class. Search these three:

| Class | Covers | Why |
|---|---|---|
| **9** | Downloadable software, mobile applications, game software | **The critical one.** Your app lives here |
| **41** | Entertainment services, providing online games | Often filed alongside 9 for games |
| **28** | Games and playthings, board games | Relevant if a physical version ever exists, and a conflicting board game here could still cause problems |

Search all three. A conflict in 9 is a blocker; a conflict in 41 or 28 is a conversation
with an IP lawyer.

---

## 3. Search terms

Run every row. Philippine examiners refuse marks that are *confusingly similar*, not just
identical — a mark can look available and still be refused, so search wider than feels
necessary.

**Exact and spacing variants**
```
DiAkoOi
Di Ako Oi
DiAko Oi
Di AkoOi
DIAKOOI
Di Ako 'Oi
```

**Phonetic / sound-alike**
```
Diako
Dyako
Di Ako
Diyako
Dakoi
Dako
Diakoy
Akoi
```

**Dominant-word searches** — examiners weigh the dominant element of a longer mark, so
these matter even inside unrelated names
```
AKO
DI AKO
OI
```
(`AKO` will return a lot. Skim for class 9, 41, 28 only.)

**Semantic / translation** — the search guidance for PH explicitly flags local-language
equivalents as a conflict source
```
Not Me
NotMe
It Wasn't Me
Hindi Ako
Wala Ako
```

**Competitor names** — the genre neighbours, to confirm none of them hold a PH mark broad
enough to cover you
```
Imposter
Impostor
Among Us
Spyfall
```

## 5. Reading the results

| Finding | Meaning | Action |
|---|---|---|
| Nothing in class 9, 41, 28 | Strong position | Proceed. Consider filing (§6) |
| Similar mark, unrelated class (food, clothing) | Usually fine — protection is per class | Note it, proceed |
| Similar-sounding mark in class 9 or 41 | **Real risk.** Confusing similarity refuses registrations even without an exact match | Get a clearance opinion before the site goes live |
| Identical mark in class 9 | Blocker | Rename. Cheap now, ruinous after store listing |

A mark that looks available can still be refused at examination as confusingly similar.
If anything in class 9 or 41 makes you hesitate, that hesitation is the signal to get an
opinion rather than to proceed hopefully.

---

## 6. Filing (optional, but consider it)

- **Local applicants may file without an agent** — you don't need a lawyer to file, only
  to interpret a marginal result. Foreign applicants must appoint a PH agent; you're local.
- File via **eTMfile**: <https://onlineservices.ipophil.gov.ph/etmfile/> — no account
  needed, available 24/7.
- The system produces a **preliminary similarity report** against pending and registered
  marks. Useful, and explicitly **not binding** — the examiner issues the official search
  as part of any office action.
- Timeline: roughly **6–12 months** to registration.
- File in **class 9 at minimum**; add 41 if you ever plan a web-hosted version.

**Worth filing?** For a free app, arguably not immediately. Worth it if you intend to
build Team Lanzones as a product brand, because the name becomes an asset. The search
below is mandatory either way; filing is a judgement call.
